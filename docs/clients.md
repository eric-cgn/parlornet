# Frontends: sources, evidence and gaps

ParlorNet brings back the protocols of old game servers. Festivals, events and private groups can run one server for many games, and people can play on it with the original game programs. Each native client (a game program of its day, such as Reversi The Eclipse or MacFIBS) reaches the server through a server extension that speaks its own protocol. Web browsers and telnet programs are the fallback, for machines without a native client. A machine whose only way out is a serial port reaches a parlor through a WiFi modem, a login on a Unix machine or a bridge, as [serial.md](serial.md) describes. When an original server is still running, the pages for its protocol and its clients say so in one line, and the page of each client whose players still have a group or server running promotes it in its Community section. FIBS is still running at fibs.com (telnet fibs.com 4321). The docs site's [Clients page](http://docs.parlornet.org/) lists each game's native clients first, with a link from each game to the browsers and telnet programs, which are listed once at the bottom under Any Game (Generic) Clients. A game with no native client says "No native client yet."

Every program has its own page on the docs site (`clients/<id>.html`), built from two sources. `adapters/clients.py` holds the structured facts: its name, the year of its first qualifying version, a short OS text, the platforms and processors it runs on (for the Clients page's finder), its protocol's key, its status, where to get it, and the groups still running for it (`COMMUNITIES`). Its Markdown page in [clients/](clients/README.md) holds the prose: its history, notes on getting it, setting it up, its known quirks and its screenshots. The [Browsers](http://docs.parlornet.org/browsers.html) and [Telnet programs](http://docs.parlornet.org/telnet.html) pages keep what every browser or telnet program needs, and link to each program's page. This file adds the licenses, the evidence that each listed program meets what the site needs, the programs left out and why, and the coverage gaps.

Links go to the author's page if it still exists, otherwise to a public archive (Info-Mac first, then Discmaster, Aminet and the like). ParlorNet redistributes none of these programs; the docs site carries only ParlorNet's own downloads. Mac OS itself is not linked.

## The retro window

ParlorNet's retro clients are game programs first released about 25 to 50 years ago, which for the 2027 release means 1977 to 2000. The window is a rule of thumb, a round line rather than a historical one, and it moves forward a year each year. New native-client work targets it, and the next server extensions and clients are picked from programs of those years. Web browsers and telnet programs are outside the rule, since they are the fallback and how any computer gets in, old or new.

## Ratings

Every client is rated for each platform, processor (or build) and version that has been tried, so one program can hold several ratings: Reversi The Eclipse 1.2 is Silver on a 68k Mac and not yet rated on a PowerPC Mac, and MacFIBS 3 r6 is rated for its 68K build apart from its PowerPC build. A rating comes only from a real test with the program itself, on that system and that version: a whole game played on a parlor, against the bot or another player. Tests with scripted clients that behave as the program does, reading its code, or the program merely starting or connecting, are recorded but earn no medal. The marks are:

- **Gold:** it works fully. A whole game plays as it should, and anything odd it does has a plain remedy, given under its Known quirks.
- **Silver:** it works once the program itself is patched, such as Reversi The Eclipse with the Eclipse 68k Fix on a 68k Mac. Add-ons and setup are not patches: GameMaster needs ParlorNet's rulebook, and NetLuff needs the parlor to publish port 1744, and both can still be Gold.
- **Bronze:** it works, but something in play goes wrong, or the program behaves differently from one time to the next, with no remedy a player can count on.
- **Unsupported**, the red "no" sign: ParlorNet examined the program and ruled it out, and its page says why. Unsupported programs have pages but are not native clients: they are not in the game tables, the summary grid or the finder.
- **Not yet rated:** nobody has played a whole game with the program itself on that system yet. The page says what has been tested instead, and what a real test needs. A client whose status is "untested" or "planned" has no medal, and the browsers and telnet programs have none until one of them is tried.

Each rating in `adapters/clients.py` is a `Rating`: the medal, the platform, the processors or build, the version, a few plain sentences of explanation and the test's date. For Gold, the explanation says what was tested, on what machine or emulator and how; for Silver, which patch and why, with a link to it; for Bronze, what goes wrong; for Unsupported, why. Every place a client runs on that has no rating is shown as not yet rated. The Clients page shows each client's medals for each game, with the version and platform beside each icon, and the summary grid shows the medals of the native clients on each machine. A client's own page lists every rating near its top, each with its explanation.

A rating changes only with a new test. A new version or platform gets its own rating once it has been played. When a test finds a fault, or a fix on the server or a new patch cures one, the rating, its explanation and its date are updated together, and the old evidence stays on the client's page.

## Coverage gaps

These are the native clients that reach each game today, and what is missing.

On the Mac (68000 and 68020 or later), GameMaster (1991) plays its own Othello, Dots&Boxes and BattleShips, and ParlorNet's rulebooks for it (2026) add Checkers, Mancala, Five in a Row, Grid Words, Rummy Tile, Cannon Fire and Backgammon, so every game has a native client there (all ten have played against the bot under an emulator). GEnie's RSCARDS front ends (1987 to 1995) play all ten games too, through the RSCARDS extension on port 6520: the Mac's color version 5.0 (Gold, under Basilisk II) and the IBM PC version 5.02 (Bronze, under DOSBox); the Commodore 128 and Amiga versions are untested. The list below names them only where they are one of several.

- **Reversi:** Reversi The Eclipse (Mac, Silver on 68k), Outland Reversi through the Outland Gateway (Mac, Gold), GameMaster's Othello (Mac, Gold) and OLIOS (SPARC Unix, untested). Missing: a native client for Windows, MS-DOS, Amiga, Atari ST and Linux.
- **Backgammon:** ParlorNet's Backgammon rulebook for GameMaster (Gold on the 68000 and the 68020), MacFIBS 3 (Gold for the 68K build), Outland Backgammon through the Outland Gateway (it has started a game under an emulator), and FIBS/W, xfibs and xibc, untested with the real programs. The RSCARDS front ends play it through the RSCARDS extension on port 6520, though the IBM PC version has stopped in Backgammon several times under DOSBox. Missing: the Atari ST (Online Backgammon for the ST is a serial peer-to-peer program, and no copy of the ST's RSCARDS front end was found).
- **Grid Words:** BobGrid (Java 1.1, Bronze: played against the bot under the Blackdown JDK 1.1.8 on Linux) and any telnet or MUD client, through the DOoM extension on port 6507; Networdz 2.0 on Windows, with the parlor as the host, through the Networdz extension on port 6516 (Gold under Wine, with ParlorNet Link beside it); and ParlorNet's Grid Words rulebook for GameMaster. Missing: a native client for MS-DOS, Amiga and Atari ST.
- **Cannon Fire:** only ParlorNet's rulebook for GameMaster. KOTH (Unix) and Dome Wars (PowerPC Mac) were examined: each of their clients simulates every shot itself, so neither can show ParlorNet's physics. BattleDuel (Amiga, peer to peer) is the other candidate found.
- **Dots and Boxes:** GameMaster's Dots&Boxes (Mac, Gold, on the 13 by 11 `majority` tables) and NetBoxes 1.1 (PowerPC Mac, Gold, on `standard` tables of any size for two to four players, through the NetSprocket extension on port 6512).
- **Five in a Row:** ParlorNet's rulebook for GameMaster, and NetLuff 1.4 (68030 and PowerPC Macs, Gold on PowerPC, on the 20 by 20 freestyle tables it makes). Candidates: connx 1.1 (X11) and Luffar (Amiga, peer to peer).
- **Mancala:** Awale 2.x on 68k and PowerPC Macs, through the Awale extension on port 6515, an IRC server of its own (Gold for its 68k code); and ParlorNet's rulebook for GameMaster. The Windows build of Awale is untested.
- **Checkers:** ParlorNet's rulebook for GameMaster, xcheckers 2.2.3 (X11) through the ICDS extension on port 6518, and the RSCARDS front ends (Mac and IBM PC, the game each has played whole against the bot) through the RSCARDS extension on port 6520. Candidate: Microsoft Internet Checkers (the Zone protocol).
- **Naval Combat:** GameMaster's BattleShips (Mac, on the `salvo` tables), and batnav's clients through the batnav extension on port 6514, on the `batnav` tables: the X, ncurses and GTK clients work, the Windows 3.x client is untested.
- **Rummy Tile Classic:** only ParlorNet's rulebook for GameMaster, and no period candidate worth an extension.

The Clients page's summary grid shows each example machine against each game. The Apple II and the Commodore 64 have ParlorNet's own programs for every game (2026, from its repository eric-cgn/parlornet-8bit, speaking PARLORNET/1): Gold on the Apple IIe under MAME and on the Commodore 64 under VICE, the IIgs's GS/OS program not yet rated; the Apple IIe's guide is [apple2.md](apple2.md). The Commodore row also has the RSCARDS front end for the Commodore 128 (untested). A 68000 Mac and a 68040 Mac have a native client for every game. A PowerPC Mac has native clients for Reversi, Backgammon and Grid Words, and a SPARC workstation for the same three. Windows has them for Backgammon (FIBS/W) and Grid Words (BobGrid). An IBM PC/AT with DOS has the RSCARDS front end for every game, and Worthy Opponent for Reversi, Checkers and Five in a Row; an Amiga 500 has the RSCARDS front end (untested). An Atari ST and a modern computer have no native client yet, so their rows show telnet ("T") for every game.

Among the fallbacks, MS-DOS has no listed browser (Arachne lacks image maps), so DOS plays by telnet (MS-DOS Kermit). 68000 Macs have one browser (Mill) and one telnet program (NCSA Telnet). The Amiga has AWeb-II and MiniTelnet, the Atari ST CAB and TelVT102. Unix workstations have no listed period browser yet (Netscape for Unix is unlinked); they play by telnet or with xfibs, xibc, OLIOS and BobGrid. The Clients page's finder shows each of these: a platform with nothing for a game says "No clients for this platform yet."
