# Q-Link (QuantumLink)

## History

Quantum Link was the online service for the Commodore 64 and 128. It opened on 5 November 1985 and closed on 1 November 1994, and its company, Quantum Computer Services, later became America Online. It grew out of PlayNET, whose system it licensed, and players reached it by modem at 300 to 2400 baud.

Its People Connection had multiplayer games: Backgammon, Bridge, Boxes, Checkers, Chess, Four in a Row, Chinese Checkers, Hangman, Quad-64, Reversi, Sea Strike and a beta of GoMoKu. Sea Strike and Hangman came on the client disk, and the other games on separate game disks; each player needs the disk the game is on. The server only passes moves between the players' machines, which run the rules themselves.

In 2005 Jim Brain studied the original server and wrote Q-Link Reloaded, a new server in Java that C64s reach over TCP. It is free software (GPL), and the service runs again today.

## Getting it

Both links are copies of the version 4 client disk, which carries Sea Strike and Hangman. The game disks are not linked here. The disks are period software that Quantum and AOL never put under a license.

## Setting it up

- ParlorNet has no Q-Link service yet, so there is nothing to set up here. A Q-Link extension is planned, starting with Sea Strike.
- To connect today, a C64 or C128 (or an emulator such as VICE) needs the client disk and a WiFi modem. The Community section below has the details.

## Known quirks

- Q-Link runs at 1200 baud. With a Zimodem-type WiFi modem dial with plain `ATD`: `ATDT` turns on telnet handling and `ATDP` translates to PETSCII, and Q-Link uses neither.
- SwiftLink-type cartridges need patched client disks.
- For any game other than Sea Strike and Hangman, both players need the game disk.
