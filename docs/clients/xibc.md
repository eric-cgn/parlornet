# xibc

## History

xibc is Jesper Blommaskog's FIBS client for X11, written as an Expectk script, a Tcl/Tk program that drives the Unix `telnet` command. Version 0.31 is dated March 1994. The archive states no license.

## Getting it

It is a script, so it needs Tcl/Tk with Expect rather than a build.

## Setting it up

- The server's address is written into the script. Edit its `spawn telnet` line to read `spawn telnet {host} 6505`.
- On ParlorNet you can play Backgammon matches against anyone on the server.

## Known quirks

- Games here are unrated, so ratings show as 0.00. Redoubles and stored messages are not offered.
