# PuTTY

## History

Simon Tatham's PuTTY was first released in January 1999. It is free software under the MIT license, and runs on Windows and Unix.

## Getting it

It comes as an installer or as a single `putty.exe`.

## Setting it up

- In Session, set host `{host}`, port `6502` and connection type Telnet. Recent versions list Telnet under Other.
- It reports itself as `xterm`, so the server picks the UTF-8 display and mouse clicks work.
