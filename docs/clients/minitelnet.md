# MiniTelnet

## History

Marcel Jaehne's MiniTelnet is new, from 2026, and runs on every Amiga back to AmigaOS 1.3. Its readme lists basic ANSI and VT100 emulation with ANSI color and IBM PC (CP437) characters.

## Getting it

Use version 0.29.

## Setting it up

- It needs a TCP/IP stack such as AmiTCP, Miami or Roadshow.
- Connect to `{host}`, port `6502`.

## Known quirks

- Whether it sends the arrow keys has not been checked. If they do not move, choose the movement keys on the Telnet programs page.
