# Netscape Navigator

## History

Netscape Navigator came from Netscape Communications. Version 1.0 already had forms and server-side image maps, and 1.1 (March to April 1995) added tables, which Netscape's press release of 6 March 1995 announced as "HTML 3.0 tables". Version 2.0 (1996) added client-side image maps and 3.0 table cell colors. TidBITS covered the 1.1 release on 13 March 1995. The company is gone, so there is no author's page to link.

## Getting it

Use 3.01 on the Mac and 3.04 on Windows.

## Setting it up

- On the Mac it wants System 7 with a 68020 or later, or a PowerPC Mac. Give it 8 MB of memory or more. It has not been confirmed on 68000 Macs, which can use Mill.
- Open `http://{host}:6500/`.

## Known quirks

Nothing known yet.
