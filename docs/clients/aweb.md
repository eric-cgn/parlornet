# AWeb-II

## History

AWeb is a web browser for the Amiga. Version 2.1 (November 1996) brought the tables promised with 2.0, and the 3.x manual (1998) lists "Tables, including table backgrounds" and "Client-side image maps". Version 3.4 was released as open source under the AWeb Public License.

## Getting it

Use 3.4, for the 68020 or later.

## Setting it up

- It needs AmigaOS 3.0 or later, 2 MB of memory (4 MB is recommended) and an AmiTCP-compatible TCP/IP stack.
- Open `http://{host}:6500/`.
