# XScrabble

## History

XScrabble is a crossword tile game for Unix workstations with X11. Matt Chapman wrote version 1.0, dated November 1994, and Jean-Pierre Demailly's 2.x versions followed, among them 2.12. Up to four people play, each at their own X display: one XScrabble program opens a window on every player's screen and runs the whole game itself.

ParlorNet looked at it as a Grid Words client. It has no network code of its own and no game protocol, only the X window system's, so there is nothing a parlor could answer.

## Getting it

NetBSD's and FreeBSD's source archives keep the 1.0 and 2.12 sources. ParlorNet links to them and serves nothing of XScrabble.

## Setting it up

XScrabble does not play on a parlor, for the reason under History. Its players can play Grid Words on the web, by telnet, in ParlorNet Play, or with BobGrid on the same machines.

## Known quirks

- Version 1.0 may be copied freely but says nothing about changing it, and 2.12 carries both the GPL and the 1.0 notice.
