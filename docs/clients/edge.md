# Edge

## History

Microsoft Edge was first released in 2015 and rebuilt on Chromium in 2020.

## Getting it

It comes with Windows 10 and later. Microsoft offers it for macOS and older Windows too.

## Setting it up

- Open `http://{host}:6500/`. With JavaScript on, a table page updates without reloading.
