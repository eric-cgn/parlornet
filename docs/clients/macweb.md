# MacWeb

## History

MacWeb is a Mac browser from EINet, later TradeWave. Version 1.x had no tables. MacWeb 2.0 (1996) added "the Netscape extensions for tables", as its own help puts it, and it has forms and a crosshair over a "regional hypergraphic image", which is a server-side image map.

## Getting it

Use version 2.0.

## Setting it up

- Open `http://{host}:6500/`.

## Known quirks

- MacWeb 2.0 quit at launch with an error of type 1 under Mac OS 9.2.2. It runs under System 7.6.1.
- MacWeb has no cookies, so your session goes in each link (`s=`). Do not pass those links on to anyone.
