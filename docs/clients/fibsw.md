# FIBS/W

## History

FIBS/W is Robin Davies' Windows client for FIBS, the First Internet Backgammon Server. It came out in 1994, and with MacFIBS it was one of the first graphical FIBS clients. Version 1.30, from January 1995, is the last one found. It ran on Windows 3.1, Windows for Workgroups and NT, and on OS/2 2.x as a Windows program. It was shareware at US$40.

FIBS/W is a terminal with a board window. It reached FIBS either straight over Winsock or by modem through a dial-up shell account, using a small script language to log in. The board window follows the server's board lines, and the rest of the session shows as text.

## Getting it

The pip count works only in a registered copy.

## Setting it up

- It needs Winsock 1.1, for example Trumpet Winsock on Windows 3.1. Windows 95 has it built in.
- In Options > Advanced Options, set the address to `{host}` and the port to `6505`. Your login name and password are FIBS/W settings too.
- On ParlorNet you can play Backgammon matches against anyone on the server.

## Known quirks

- Only the board is drawn in a window. The player list, invitations, the start and end of a match and chat all appear as text in the terminal, so answer them by typing commands such as `join` and a name.
- Games here are unrated, so ratings show as 0.00. Redoubles and stored messages are not offered.
