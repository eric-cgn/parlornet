# Internet Explorer

## History

Microsoft's Internet Explorer 2.0 for Windows (November 1995) had tables, forms and image maps, including client-side maps, which a www-html post of December 1995 discussed. Microsoft's release of 23 April 1996 announced 2.0 for the Mac with "HTML 2.0 and 3.0 tags". Windows came with it from Windows 95 OSR2 on.

## Getting it

Use 2.1 or 3.01 on the Mac, and 3.02 on Windows 95.

## Setting it up

- On the Mac, 2.1 needs a 68030 or better (or a PowerPC Mac), System 7.1 and 8 MB of memory, by its release notes.
- Open `http://{host}:6500/`.
