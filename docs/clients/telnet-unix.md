# telnet (Unix, Linux, macOS)

## History

The BSD telnet client shipped with 4.2BSD in 1983 and has been part of Unix systems since.

## Getting it

Unix systems and Mac OS X up to 10.12 have it built in.

## Setting it up

- Type `telnet {host} 6502` in a terminal window such as xterm, Terminal, iTerm, GNOME Terminal or Konsole.
- The terminal does the drawing and reports its type and size.
