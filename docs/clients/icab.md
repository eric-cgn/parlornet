# iCab

## History

iCab is a Mac browser by Alexander Clauss, who wrote CAB for the Atari before it. Its first preview, in February 1999, supported HTML 4.0, which includes tables, forms and image maps; TidBITS reviewed it on 1 March 1999. The author still offers the classic versions on his site.

## Getting it

Use 2.9.9 on 68k Macs (Mac OS 7.5 to 8.1) and 2.9.9 or 3.0.5 on PowerPC Macs. The archives need StuffIt Expander 5 or later.

## Setting it up

- Open `http://{host}:6500/`.

## Known quirks

- The 1999 TidBITS review said the first preview "seemed to have trouble with some HTML forms". Whether the later versions linked here do has not been checked.
