# Mill

## History

Mill is a web browser for black-and-white and color Macs back to the Mac Plus, from OneInAMillion Software, first released in 2026. Its change log shows tables arriving in 0.3, forms in 0.4 and client-side and server-side image maps in 1.5, the first version with everything the site needs. Version 1.5.4 added dark cell colors. Menus (SELECT) are in its form code. Version 2.1.2 is the one to use.

## Getting it

Mill is freeware.

## Setting it up

- It needs a Mac Plus or later, System 6.0.3 or later (6.0.8 is recommended), MacTCP 1.1 or later and 1 MB of memory (2 MB is recommended). It runs on 68000 Macs such as the Plus, SE, Classic and PowerBook 100.
- Open `http://{host}:6500/`.

## Known quirks

- On a 1-bit screen it draws dark table cells black with white text. The site keeps its text on light cells, so pages stay readable.
