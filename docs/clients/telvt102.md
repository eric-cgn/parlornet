# TelVT102

## History

Boris Cahan's TelVT102 is a VT102 terminal for the Atari ST, STe, TT and Falcon, with its own fonts and line graphics. A 1998 post in comp.sys.atari.st called it the best VT100 client for the ST. Its release date was not found.

## Getting it

Use version 2.02r.

## Setting it up

- It needs the STinG TCP/IP stack.
- Connect to `{host}`, port `6502`.

## Known quirks

- Its line graphics are VT100 ones, not IBM PC characters, so pick the `ansi` display.
- Whether it sends the arrow keys and shows color has not been checked. If the arrows do not move, choose the movement keys on the Telnet programs page.
