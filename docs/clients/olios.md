# OLIOS

## History

OLIOS is "the OpenLook X-client for IOS", the Internet Othello Server. Michael Buro wrote it on top of Igor Durdanovic's reference client code, and the 0.95 sources are dated 1994 to 1995. It ran on Unix workstations with X11 and the XView (OpenLook) toolkit. The source was on Buro's page at the NEC Research Institute, which survives in the Wayback Machine, and a SunOS 4 SPARC binary from 1996 is in the ftp.update.uu.se Othello archive. The archive has no license text, and its copyright notice names Igor Durdanovic.

ParlorNet's IOS service follows what the OLIOS source parses, as well as what Reversi The Eclipse reads.

## Getting it

The source needs the XView (OpenLook) toolkit to build.

## Setting it up

- Point it at host `{host}`, port `6503`, as its README says for an IOS server.
- On ParlorNet you can play Reversi against anyone on the server, as with Reversi The Eclipse.

## Known quirks

- Current Linux distributions no longer carry XView. OLIOS 0.95 builds unchanged on Debian 8 (x86-64), which still has it.
- IOS login names are at most 8 letters and digits.
- Games here are unrated, so there are no ratings to see.
